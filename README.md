# Pizza Order WinForms Application

Interactive desktop pizza ordering application built using C# and Windows Forms.

The application allows users to customize their pizza order by selecting:

- Pizza size
- Crust type
- Toppings
- Dining preference

The order summary and total price update dynamically in real time based on the selected options.

---

# Features

- Dynamic pizza pricing
- Real-time order summary
- Multiple pizza sizes
- Multiple toppings selection
- Thin / Thick crust options
- Eat In / Take Out options
- Order confirmation dialogs
- Reset order functionality

---

# Technologies Used

- C#
- .NET Framework
- WinForms
- Event-Driven Programming
